## 核心原则
- 官方信息≠官方品牌推荐：国家监管抽检只解释合规范围与具体不合格项目；不能生成“国家推荐品牌”。
- 地方消费者组织比较试验能解释不同产品的场景适配、性能与代价；若样本来自2022年，只是历史比较试验，绝不能声称2026年的实时价格或品牌排行。
- 厂商技术支持可解释机型工作原理、维护条件，但涉及利益相关性；两篇同一厂商FAQ不是两个独立来源。
- 自媒体/知乎/小红书可作为待核验问题、反例和主观使用体验，不替代独立实测或监管报告；商业推广明确标记。
- 必须记录适用条件、例外、来源URL、发布日、采集日、反证状态、再分发边界；缺反证记“未取得”，不写成“没有反证”。
- 证据数量应按不同组织、不同采样事件去重统计。13张卡来自5份不同源文献，不能宣传“13家官方支持”。
- 50/150页并非官方行业阈值，属于S0示例和本地工程分组，不可对外作为权威法则。
- 原文版权：仅保留自行归纳的简短陈述与可追溯链接，不缓存原文图表、PDF全文或者爬取数据库；公开可访问不等于允许再分发，商业用途需另行核实。

## 开源组件评估（未复制源码）
1. RAGFlow https://github.com/infiniflow/ragflow ：文档解析、分块、元数据与可追溯引用；Apache-2.0。等知识卡规模/复杂PDF明显增加，再试模块化引入；当前13张卡不值得上重型服务。
2. FastGPT https://github.com/labring/FastGPT ：中文文档导入、知识检索、可视化工作流和来源反馈成熟；是自定义 FastGPT Open Source License，对 SaaS 等有约束，不能当无条件MIT/Apache项目。
3. Dify https://github.com/langgenius/dify ：知识库元数据管理（来源/时间/标签）与工作流容易演示；Dify Open Source License 基于 Apache-2.0 有附加条件，适配与商用前检查。

本轮未发现已核准“全国消协比较试验完整数据、可自由商用和再分发”的官方开放数据库或API；此结论只表示本轮未验证到，并不证明不存在。优先自主整理有出处的知识卡而不是批量爬站。
