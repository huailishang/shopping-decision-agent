# 京东 / 淘宝接入与支付边界

## 分阶段接入

- **L0 离线模拟（当前）**：合成 SKU、商品评价、报价、订单草稿；0 账号、0 网络、0 支付。
- **L1 只读商品查询（待接入）**：优先官方授权 API 与合规聚合数据；必要时用户授权的浏览器/手机操作，不绕验证码/反爬/登录风控，记录来源及查询时间。
- **L2 用户授权操作（待接入）**：加购物车/填写商品规格、地址等任何副作用都必须有该动作的明确授权、可取消；不保留真实用户隐私在测试日志。
- **L3 提交订单/支付（非当前范围）**：需要商户或平台合法支持，以及明确逐单金额、SKU、商户、收款方、地址等确认；实际支付一律交给可信支付实验台的有授权环境，不以 UI 脚本绕过支付验证。

## 平台区别

**2026-11-07 下一轮选品渠道限京东联盟、淘宝、小红书**；已排除拼多多，支付宝不作为商品检索源。当前只做有来源的只读发现、价格条件核实和合法评价证据，**不登录或创建交易**。详见 [渠道方案](08_商品发现与评价证据渠道_京东淘宝小红书.md)及[评估者执行包](../handoffs/P0_2_京东淘宝小红书_商品发现与评价证据_评估者执行包_20261107.md)。

| 场景 | 可能接入方式 | 验证点 |
|---|---|---|
| 京东联盟商品发现 | JOS/京东联盟商品查询与详情（申请适用权限后只读） | 推广池范围、开发者准入、联盟 ID 与 SKU、展示/比价用途、销售项价格/地区库存/费用，不能仅凭目录视作接通 |
| 淘宝商品发现 | 淘宝客推广者物料搜索、商品详情（申请适用准入后只读） | “不需要授权”接口标签不等于无 AppKey/签名；需核物料覆盖、准确型号、销售配置与用户实际结算价 |
| 小红书体验/反证 | 官方内容合作许可或用户主动提交且允许分析的少量资料 | 店铺商品 API 不等于全站笔记/评论读取；确认来源、时间、型号、授权、广告/重复风险 |
| 账号登录 | 本轮不要求、不代操作消费者登录；将来若涉及用户本地操作需另定授权 | 不持久化登录、不索取密码/Cookie，不把第三方自动化当默认接入 |
| 交易确认 | 用户在平台或可信支付沙箱操作（非本轮） | 精确对应订单金额、SKU、数量、收款方及支付结果 |

```json
{
  "draft_id": "synthetic-draft-001",
  "platform": "mock",
  "sku_id": "synthetic-printer-001",
  "quantity": 1,
  "currency": "CNY",
  "amount_minor": 0,
  "quote_observed_at": null,
  "user_confirmation": "NOT_GRANTED",
  "side_effect_allowed": false,
  "source_evidence_ids": [],

```

示例仅是**无交易权限的草稿契约**。含金额字段不意味着可发起支付；真实交接需要目标系统重新核验和授权绑定。
