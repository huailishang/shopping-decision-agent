# 京东 / 淘宝接入与支付边界

## 分阶段接入

- **L0 离线模拟（当前）**：合成 SKU、商品评价、报价、订单草稿；0 账号、0 网络、0 支付。
- **L1 只读商品查询（待接入）**：优先官方授权 API 与合规聚合数据；必要时用户授权的浏览器/手机操作，不绕验证码/反爬/登录风控，记录来源及查询时间。
- **L2 用户授权操作（待接入）**：加购物车/填写商品规格、地址等任何副作用都必须有该动作的明确授权、可取消；不保留真实用户隐私在测试日志。
- **L3 提交订单/支付（非当前范围）**：需要商户或平台合法支持，以及明确逐单金额、SKU、商户、收款方、地址等确认；实际支付一律交给可信支付实验台的有授权环境，不以 UI 脚本绕过支付验证。

## 平台区别

| 场景 | 可能接入方式 | 验证点 |
|---|---|---|
| 京东商品查询 | 开放平台/企业采购 API/合法导购接口/授权 UI | 是否具备真正商品详情、SKU、价格/库存权限，不等同于通用买家订单 API |
| 淘宝商品查询 | 淘宝开放平台/淘宝客商品信息能力/授权 UI | 导购接口不能当作个人账户通用下单/付款接口 |
| 账号登录 | 由用户在本地浏览器/App 手工登录 | 验证会话隔离、失效、撤销，不能让智能体获取明文密码 |
| 交易确认 | 用户在平台或可信支付沙箱操作 | 精确对应订单金额、SKU、数量、收款方及支付结果 |

```json
{
  "draft_id": "synthetic-draft-001",
  "platform": "mock",
  "sku_id": "synthetic-printer-001",
  "quantity": 1,
  "currency": "CNY",
  "amount_minor": 0,
  "quote_observed_at": null,
  "user_confirmation": "NOT_GRANTED",
  "side_effect_allowed": false,
  "source_evidence_ids": [],
  "idempotency_key": null
}
```

示例仅是**无交易权限的草稿契约**。含金额字段不意味着可发起支付；真实交接需要目标系统重新核验和授权绑定。
