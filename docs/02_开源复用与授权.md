## 百度（服务适配器）

- 官方入口：https://openai.baidu.com/
- 确认文档：百度优选公开说明确实开放「商品百科知识、榜单、全维度参数、商品理解」及电商搜索 Skill。
- 待办：按官方权限申请路线核验是否能拿到结构化品类知识、访问频控、资费、缓存和再分发限制；不可把页面宣传语等同于已获 API。
- 实现原则：先 Mock 契约测试，再接真实 API；严禁把 API Key 提交 Git。

## 球球（实现参考）

- 源码：https://github.com/pingfangww/qiuqiu-rag-shopping-agent
- 取其「知识在推荐之前、缺失关键条件先追问、价格等确定性事实不能让模型生成」思路。
- 待办：核对 LICENSE/作者授权、依赖许可证、商品数据来源；若条款不明确，用独立实现替代复制。
- 优先拆出的接口：澄清器 / 文档检索器 / 评价证据关联 / 商品对比 / 建议输出。

## 双基准（独立基准适配）

1. **ShopSimulator**：https://github.com/ShopAgent-Team/ShopSimulator
   - 侧重中文复杂购买偏好、多轮搜索与交互，输出是否找到了合适商品、是否满足用户偏好、轮次与工具调用。
   - 先建立任务格式适配器；不直接污染真实评测样本。
2. **EComAgentBench**：https://github.com/Morizeyao/EComAgentBench_
   - 公开说明 662 条任务、隐藏意图分布在多种来源、100 次交互预算、最多 10 轮追问，须避免只看表面问题。
   - 数据来自 Amazon Reviews 2023；需要确认下载限制、API Key、Python 3.11 运行环境，不应假设直接支持国内平台。
   - 先提供 unified episode 格式，独立保留上游 gold、评价标准，不能改变上游成绩定义。

## 复用顺序
1. 本项目独立写契约、样例、可运行基线（当前阶段）。
2. 逐一审查 3 个代码仓与百度服务接入权限，记录 commit/版本/许可证。
3. 在 `external/` 下可选单独 checkout（不作为核心源码目录、不默认随 Git 发布），按 Adapter 方式复用。
4. 先本地跑上游原始基准，再运行统一适配后的相同样本，比较迁移前后偏差；禁止称“合并了 Benchmark”但未跑上游原始脚本。
5. 只有形成反复出现的能力差距才增加新模块，不预铺组件目录。
