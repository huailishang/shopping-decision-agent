# 海纳商品检索离线导入与许可门禁

## 当前状态

海纳商品检索 Pro 已有一次本机只读调用成功，但《MCP开发者合作协议》全文、上游数据供给权和本项目的数据使用许可尚未核清。因此：

- 真实响应导入保持关闭：shopping_decision/haina_ingest.py 中 REAL_RESPONSE_IMPORT_ENABLED=False。
- 只允许 source_mode=synthetic_test 的合成输入进入解析器。
- 不重复调用海纳 API，不读 API Key，不将原始 20 条兄弟打印机响应导入项目。
- 用户展示、缓存/审计摘录、第三方模型处理、再分发、推广链接/非分佣用途均保持未知或关闭，见 reports/P0_9_海纳数据用途矩阵与真实样本阻塞_20261110.md。

## 离线导入契约

入口：

- shopping_decision.haina_ingest.ingest_haina_product_search(payload, observed_at=..., source_mode="synthetic_test")
- 只接受业务码为整数 0、有限大小 JSON、最多 20 条记录和有效观测时间。
- union_spec 若为 JSON 字符串，使用 json.loads 安全解析；不执行字符串。
- 输出是 source_lead_only 线索，不是候选商品、平台身份、价格或购买建议。

保留的最小字段：

- 标题、品牌提示、商城提示、店铺提示、类别提示；
- 标题型号候选、规格型号候选及冲突状态；
- 推广链接类型（只识别域名类别，不保存完整 URL，不解析参数）；
- 主机/耗材提示、新旧提示、多型号/套餐歧义提示；
- 观测时间和待核字段。

明确不导入：

- 完整推广 URL、URL 参数或猜测的 SKU/平台商品 ID；
- price、page_price、score、评论数量/好评率、图片；
- 外部输入携带的 identity_verified、quote_verified、purchasable、批准字段。

## 候选池与正常文本入口

没有平台商品 ID 的线索由 discovery_pool 单独放在 unverified_source_leads，不进入 candidates，不进入价格比较。正常文本入口最多展示 3 个型号事实候选，并在存在时保留一个明确排除样本；海纳来源线索最多展示 3 条，同时报告总数。

合成测试入口：

```bash
python -m shopping_decision.dialogue_flow --haina-report path/to/synthetic-haina-report.json
```

不传参数时，文本入口保持原有行为。启动不联网。报告必须是 synthetic_test；真实响应在用途许可未核准时会被阻断。

## 放开真实数据的条件

只有拿到可核验协议/书面答复，并明确本机解析、用户展示、缓存/审计、模型处理、再分发、推广链接/非分佣等适用范围后，才能重新评估真实导入开关。Key 有效、HTTP 200、接口返回成功都不是许可依据。

放行后按 P0.9 原顺序核验原 20 条，最多深入 6 条；至少 2 个不同型号必须有平台 ID 和所售配置绑定依据，否则 AC4 不通过，不降低标准。
