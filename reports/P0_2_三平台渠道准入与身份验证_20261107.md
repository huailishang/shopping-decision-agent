### 关键区别

- 京东联盟、淘宝客是**推广商品池**：平台开发者 API、平台商品销售项、厂商型号是三层不同对象，不保证覆盖全商城或用户所选套餐。
- **商品 ID 不可跨平台转换**。淘宝详细详情接口的 `biz_scene_id=2` 是值得申请验证的明确线索，并非本项目已经获批比价用途。
- 小红书短期体验和营销帖子只可作为风险线索；未获明示许可时不得复制评论库、使用 Cookie 抓取或根据点赞数计算故障率。

## 2. 最小工程验证范围

- 新增 `shopping_decision/listing_identity.py`：对平台与原样商品 ID、型号锚点、用户选中配置、店铺、地区、来源 ID 和观察时间进行最小校验，拒绝错型号/多型号，套餐、缺卖家、无型号锚点保持待核。
- 无论合成样本是否匹配，都返回 `identity_verified=false`、`quote_verified=false`、`purchasable=false`，**只形成候选**。与原有 `retail.py` 的地区报价门禁独立，不让合成记录进入正常商品/Java 界面的真实报价。
- `tests/test_listing_identity.py` 为离线合成数据，含错型号、同系列后缀、套餐/耗材、缺来源、未来时间、跨平台 ID 不混并、外部指令不改变购买状态。

## 5. 继续/暂停判断

当前最重要的外部依赖是由授权主体核定京东联盟与淘宝的应用准入及“消费者购物比较”数据用途。若比价用途不被许可，停止该 API 路线；无需开发空平台适配器。外部授权之前，优先守住原比较的证据拒绝、暂缓和无副作用边界；恢复接入后再验证真实销量项与报价。
