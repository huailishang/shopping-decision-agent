# 消费者比选数据合作与服务商核查（2026-11-09）

结论：找到了可具体进入授权核验的服务，优先是**什么值得买海纳开放平台**，百度优选作为备选；还没有一家能凭本轮公开材料同时确认“不需我们加入联盟、不参与分佣、供数及模型用途许可明确、覆盖本案京东/淘宝销售项与个人地区到手价”。前次笼统的“找有供数权的服务商”应收敛为以下具体候选和待核条款，不能先宣布路线已经打通。

本轮已实际读取海纳未登录的开发者工作台、商品 REST 文档、MCP 文档及 Beta 公告；没有注册、申请 Key、联系供应方、调用商品业务 API、安装第三方代码或复制知识图谱数据。最新 P0.8 是另一个执行者交付，本轮不重新验收它，也不覆盖其状态。

## 1. 先把“非联盟”拆清楚

三件事不能互相替代：

1. **我们无需注册京东联盟/淘宝客**：可以由另一个有权供数的主体提供服务，但仍可能需要在该服务注册开发者。
2. **我们不参与推广分佣**：需要服务协议允许单独购买/测试数据能力，不要求转推广链接、订单归因或佣金结算；不提现不能作为没有推广关系的证明。
3. **数据不是联盟池、且可中立覆盖市场**：还要核查上游来源与商品覆盖；前两项成立也不能证明第三项。

“供数权”也不能只理解成供应商拿出一把京东 AppKey。应核定提供的数据是什么、来源和可许可依据是什么，以及其协议是否允许我们检索、向用户展示、必要缓存、交给模型处理。供应商自有内容和检索结果，和电商平台的直接授权响应是两种来源；我们的程序必须保留这一区别。服务商的 API 不应被标成“京东官方实时核价”。

## 2. 首选进入授权核验：什么值得买海纳

### 已取得的具体技术证据

官网：[海纳开放平台](https://ai.zhidemai.com/)。本次网页读取工具多次超时，直接 HTTP 曾仅取得 1024 字节壳页；随后使用无账号的独立浏览器上下文成功打开真实前端，因此以下不是单凭搜索摘要推断。

- [开发者工作台](https://ai.zhidemai.com/haina-platform)公开列出登录/注册、申请 API Key、开通能力、调试调用的流程。页面说明手机验证码首次登录自动注册，测试 Key 申请后需审核；未登录公开步骤没有要求先绑定京东联盟或淘宝客。**没有因此断言申请表审核阶段不需要额外资质。**
- [商品检索 Pro 文档](https://ai.zhidemai.com/haina-platform/product_search_pro)给出 `POST https://gw-openapi.zhidemai.com/product/v1`，请求头使用 `x-api-key`。支持商品词、商城、品牌、类目、整数价格范围、排序和字段裁剪；返回链接、标题、商城/店铺及价格信息等结构化字段。可按此设计少量候选发现实验，不必先做整套知识图谱或交易。
- [MCP 文档](https://ai.zhidemai.com/haina-platform/haina_mcp)提供 Streamable HTTP 接入；与 REST 共用 Key，但需要单独开通相应能力。它只是另一种调用方式，不能放宽数据使用权限。

这些证据使海纳比纯粹展示“全网 API”的宣传页更具体、更贴合购物决策用途。公开产品存在与公开调用规范已经核实，本应用实际准入与数据正确性未实测。

### 当前不能忽略的限制

现场公告明确：平台处于 **Beta**，面向符合《MCP开发者合作协议》的模型应用接入、验证和联调；接口策略可能调整，暂不承诺正式环境级稳定性或 SLA。测试免费不等于生产免费，也不等于可以无限调用。

未核定事项：

- 未取得所提合作协议的完整可审正文和本项目适用许可；不能确认可以只付数据服务费、不参加转链/分佣。
- 未取得京东、淘宝具体上游来源/供数依据、平台覆盖比例及联盟商品比例的材料。旧版官方介绍还提到交易联盟等方向，不能据此宣传完全脱离联盟。
- 尚未确认个人研究者能否通过审核、生产计价、额度、QPS 和可用性承诺；本轮不填写手机号、不发验证码。
- REST 公开字段概览没有证明能取得准确选中套餐、个人券资格、地区库存及完整有效期。`page_price`、`price`、历史价不能直接成为本案的授权地区到手价。
- 商品 ID/型号映射、来源时间、原始证据及是否允许回放/缓存须用真实样本和协议验证。站方宣传的准确率和覆盖量是供应方口径，不是本项目成绩。

### 本轮判断

**列为第一候选，但只进入协议/资格/样本核验，不列为已批准供应商。** 优先只申请商品检索所需能力。品牌榜单、口碑摘要、图谱知识仍须分别判断证据资格，不因接入同一平台而整体批准。

公开合作入口为官网工作台及“联系商务”。[旧版官方接入说明](https://ai.zhidemai.com/mcp)搜索索引曾列 `group-content@zhidemai.com`；本轮该旧路径直连失败，正式联系以当前官网公布方式为准。本轮没有发送消息。

## 3. 备选：百度优选，工具与分佣有区分，但上游及现网还要核实

官方入口：[主页](https://openai.baidu.com/)、[权限申请](https://openai.baidu.com/auth)。本次隔离浏览器实际看到“工具权限”“分佣权限”分开展示，工具集合同时含商品检索/详情及订单、售后等动作。

这提供了只开工具、不接交易分佣的核验方向；**页面区分不等于已经证明我们能获得完全非分佣、非联盟商品源。** 商品集合可能带交易属性，必须问清。

[全网比价详情](https://openai.baidu.com/detail?groupName=bijia)官方搜索索引曾列 SPU 与商品检索工具、Token 及示例中的 `cpsApi`、`cps_url`。本轮现场该详情只显示壳页，未取得完整说明，不能将缓存中的工具名认定为现网已可调用。Token 申请资格、费用和使用条款未核定，未取得 Token。

因此百度优选作为第二候选，需确认当前有效商品检索文档、只读工具授权、是否强制推广链接、是否能依法提供非推广商品身份/链接及京东淘宝覆盖。不能擅自去掉追踪参数来假定满足协议。工具集合有写操作时，今后连接也必须限制到搜索/详情，不整组交给模型任意调用。

## 5. 发送申请前，应审清的六件具体事

以下也是为海纳优先准备的询证文本，本轮**只形成草稿，没有发送或联系**：

> 我们开发一个以打印机为首个验证品类的购物决策研究原型，需要商品候选发现和有来源的字段比较，不开展自动下单、支付或交易分佣。请提供以下材料及适用条款：
>
> 1. 是否接受个人研究/本机原型申请？能否只开通商品检索，且不注册京东联盟/淘宝客、不绑定推广位、不参与订单归因与佣金结算？
> 2. 京东/淘宝商品来自哪些渠道？请按数据类别说明合法来源及可供本应用使用的依据，提供可核验的授权/许可说明或相应合同条款，明确是否主要限联盟池。
> 3. 是否允许我们向用户展示检索结果、交给指定模型进行比较、短期缓存并保存必要来源摘录/哈希用于审计？与训练、批量建库、再次分发的边界分别是什么？
> 4. 是否可提供非推广的准确销售项身份及链接？如只能返回推广链接，能否仅用于研究比较；是否允许并如何展示，不能擅自修改链接？
> 5. 请提供少量兄弟/惠普打印机查询样本与字段说明：平台商品ID、准确型号、店铺、套餐、价格口径、来源时间、地区库存/有效期及缺字段说明。能否明确哪些是供应商检索结果，哪些有平台直接核验依据？
> 6. Beta 测试额度、生产费用、调用/缓存限制、停服与删除规则、稳定性承诺是什么？用户输入和调用记录如何保存，是否用于训练或其他用途？

供数材料不一定是公开授权书；可采用供应商提供的可核主体、数据类别、许可范围与权利保证，并由可访问的原平台材料或合同交叉核验。仅有营业执照、ICP备案、API Key、一个正常返回或“官方合作伙伴”标签，均不能单独完成这项验证。

## 6. 获准后的最小实验，而不是先写适配器

先冻结少量打印机任务及人工对照，拿到获准测试 Key 后只调用必要的只读检索。建议涵盖泛需求、准确兄弟型号、准确惠普型号、主机/耗材混淆、自动双面条件及旧价冒充现价等情况。不得把合成响应或公开样例计为真实商品查询。

验收应分别记录：

- 查询成功、准确销售项发现、型号/店铺/套餐核对的数量；没有检出同样保留分母。
- 引用与字段出处、取证时间、未知字段；不把口碑模型摘要当独立评测。
- 无个人账号和 Cookie 条件下能取得什么；没有身份/地区报价能力时继续只作候选线索。
- 是否强制返佣/推广链接、是否可按非佣金因素排序、所见商品池是否偏向联盟。
- 只读边界、密钥本机保存、日志脱敏、限额和费用；不挂载订单/支付工具。

现阶段无需接入支付账号，不下载知识图谱全量数据，不复制第三方实现。没有通过用途许可与样本核验前不扩大本地引擎或付费承诺。
