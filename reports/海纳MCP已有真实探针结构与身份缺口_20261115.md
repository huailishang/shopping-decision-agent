## 本轮代码对这些结构做了什么

- 以 4 类真实工具结构为依据，建立合成测试夹具；夹具值全部虚构，固定 SHA-256 为 `bd1de6e313b6fcfd854e53287e5a2d91363a9c697790e984c7a5df97cd61db0d`。
- 记录供应商 SPU/SKU/商品 ID 与平台 ID 分离；`platform_item_id` 固定为空，供应商价格只作为未核验提示。
- 记录 `sku_count`、`sku_products_count` 与实际数组长度；空商品数组不再伪造一条空销售线索。
- 保留 M232dw/M232dwc 冲突、配件、二手、套装/多型号歧义；不允许这些线索进入可购买候选。
- 评价的 `count` 标为供应商报告计数，不是独立核验样本数；参数 `confidence` 也不升级为独立概率。
- 普通 CLI 不自动加载；只有用户显式选中固定夹具时才显示合成接线结果。

## 真实数据使用边界与确切缺件

11份探针摘要都写明 `raw_response_saved=false`。因此：
1. 目前不能重放或重新解析完整真实响应；SHA-256只校验当时响应字节的摘要，不能还原响应。
2. 不能把摘要里的少量标题、店铺、价格提示当作完整商品目录、完整商品事实或可独立审查的来源证据。
3. 完整《MCP开发者合作协议》及本项目所需的本机解析、展示、保存、缓存、模型传输等具体用途许可仍未取得；不新增真实响应解析或展示。
4. Brother HL-L1238W 的平台身份缺口是明确的字段缺失；HP M232dw 虽有供应商ID字段，仍缺平台原生 ID 对应证明。
5. 两个型号均缺当前地区的有效销售配置、库存、券、运费和实际到手价。
