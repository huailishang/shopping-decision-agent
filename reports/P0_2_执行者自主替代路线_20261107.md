# P0.2 执行者自主替代路径：有限尝试后的统一结论（2026-11-07）

## 目标、权限和停止条件

评估者既定目标为单一打印机品类：找到 HL-L1238W、HP Laser 108w（4ZB80A）、HL-L1228 的可追溯候选销售项，核准价格/配置/地区，并保持原需求的硬条件和购买安全门禁。本轮不获授权业务 API、登录、Cookie、交易权限，也不提交 Git。

在 API 路线无法直接执行时，由执行者**先独立跑替代路径，再一次性汇报**。每一路径最多一轮合理只读探测；出现登录/访问限制、法律和数据条款不明立即停止，不能用模拟数据充数。

### 增量量化

- 当前已核厂商目录外部发现：**Brother 9款**、其中新增未核事实型号 6款（来源：2026-11-07 重新读取官网；这不是9款合格推荐）。
- 京东/淘宝**授权真实 API 搜索 0次、合法核价销售项0、有效地区到手报价0**；公开京东商品页 2 次访问均未取得详情。
- 本轮对原用户的购买决策仍是 `defer`（暂缓），实际价和库存未知，交易保持关闭。

## 执行者独立选定的一条后续路线

**选择“厂商事实 + 可公开核实的零售入口线索”双层只读路线**，不用要求评估者再逐条出主意：

1. 原三型号先保留官网参数/微信工作流/耗材适配；兄弟官网目录可自动发现候选，HP 仍按已存的官方规格证据，不擅自扩大品类和型号。
2. 对京东/淘宝的公开商品链接、导购文章、用户自愿提供的少量商品链接只登记**潜在销售项**，保留精确 URL、来源、观察时间与待验证字段；使用现有 `listing_identity.py` 拒绝错型号、耗材、套餐混淆。
3. 对公开页面无法读出的卖家、选中配置、地区库存、真实价、运费、优惠资格，继续保留**未知**，不编价，不因导购参考价接近1000元而升级可购买。
4. 如后续合法开放本应用 API 权限及用途许可，才在已有候选上做最小2–3型号真实搜索/详情与报价校验。否则不在新账号/条款上消耗轮次；可用用户自愿提供的报价证据做人工待核，但不冒充已完成授权实时核价。
5. 一次性提交本报告、原始探针索引与可复现命令，交评估者仅做**独立验收和方向裁决**，不请其选择搜索词或指导每个工程重试。

**为什么选这条**：本轮路径3确实产生可复核发现；路径1是权限问题无法靠换 SDK 解决，路径2受限不能持续碰撞，路径4只能补零售入口。比反复提“申请接口”或盲目安装第三方 MCP，更能稳步扩充有来源候选且不污染价格门禁。
