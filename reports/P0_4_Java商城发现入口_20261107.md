# P0.4 Java 商品发现入口：执行者实际交付报告（2026-11-07）

**角色**：执行者；继 P0.3 三开源审读后独立推进一轮。**验收性质**：本机 GUI 源码编译及 Java↔Python 真实子进程联调；GUI 人工鼠标与打开浏览器的跨系统验证仍待独立评审。本轮没有声称获得京东官方业务 API 授权。

## 1. 为什么执行这一最小任务

P0.3 的 `discovery_ingest.py` 已支持严格导入商品搜索快照，但没有接到正常使用流程。长期方向仍是获授权的京东联盟/淘宝联盟 API 自动检索；当前没有可用权限时，执行者选定**前台用户可操作的合法降级入口**：Java 桌面打开官方商城搜索页，用户自行浏览并贴回个别候选 URL，应用只对 URL 做离线防错与审计。

这不是用品牌官网建立商品池；搜索端是京东商品搜索页，支持输入任意商品类别（冰箱/耳机/打印机），不需要针对每一品类重新编写 URL 处理代码。但用户还需自己选择链接，**没有自动商城搜索**。

官方接口仍是 `jd.union.open.goods.query` 等，需要京东联盟开发者身份/应用密钥/用途准入；参考 [京东官方介绍](https://jos.jd.com/jdunion)、[2026迁移通知](https://jos.jd.com/doc/channel.htm?id=994)。不能将买家京东登录态当商家/联盟 API 权限。

## 2. 本次实际改动

- **Java Swing 正常入口** `desktop/ShoppingDecisionDesktop.java`：
  - 第一页与结果页新增「京东商城商品发现（只读实验）」按钮；独立弹窗，**用户点击**「在本机浏览器打开京东搜索」后使用 `Desktop.browse` 打开由编码关键词构造的固定 HTTPS 京东官方搜索 URL。
  - 不嵌入浏览器、不读取会话/账户信息，不连接 Playwright、不会自动登录。用户从商城挑选商品详情链接，每行一条（最多5个），点击「校验粘贴的链接（不联网）」。
  - 后端仍采用 H10 `DesktopBridgeClient` 真实子进程与安全 Base64 协议；GUI 预览候选和完整 JSON，不默认保存本机或上传文件。原打印机流程保留，独立弹窗不会提升购买建议。
- **Python** `shopping_decision/discovery_bridge.py`：`shop_search_url` 固定京东/淘宝搜索入口并校验查询词（GUI 本轮只打开京东）；`review_user_links` 调用 P0.3 `ingest_user_jd_item_link` 拒绝外域/伪域、纯数字和重复 SKU。结果区分候选/拒绝，统一标 `quote_verified=false`、`authorized_api_calls=0`、`transactions_enabled=false`。
- **Python 测试** `tests/test_discovery_bridge.py` 新增12项（含 Java 一致的CLI实际子进程），**Java 测试** `desktop/P04MarketplaceRegression.java` 新增4项（含编码 URL、非法搜索词、3条销售项跨语言传递、假京东域名拒绝）。

**注意**：输入 URL 本身只证明格式合理，既没有实际访问 URL，也没有读标题或选中配置，不能判断该商品是打印机、耗材、套餐还是拼接链接；因此未将其强行与型号目录匹配或排序为推荐。

## 3. 复现命令与结果

在项目根目录，WSL/Linux 为 `python3`，Windows 可使用 `python`：

```bash

python3 -m unittest discover -s tests -q
# 旧防事故探针
python3 -m shopping_decision.h05_probes
# Java 17+ 编译与实际子进程联调
javac -encoding UTF-8 -d /tmp/shopping_p04_desktop_javac \
  desktop/DesktopBridgeClient.java desktop/ShoppingDecisionDesktop.java \
  desktop/H10JavaRegression.java desktop/P04MarketplaceRegression.java
java -Djava.awt.headless=true -cp /tmp/shopping_p04_desktop_javac \
  P04MarketplaceRegression python3
java -Djava.awt.headless=true -cp /tmp/shopping_p04_desktop_javac \
  H10JavaRegression python3
git -c core.whitespace=cr-at-eol diff --check
```

2026-11-07 本轮实际结果：Python **181/181 PASS**，旧防事故 **8/8 PASS**，P0.4 Java **4/4 PASS**，之前 H10 Java **6/6 PASS**，`javac` 构建及 CRLF 兼容差异检查通过。正常 `web.evaluate_input` 原打印机模拟需求重放：`recommendation=defer`、产品候选5、`purchase_recommendation_approved=false`、`transactions_enabled=false`。

**限制**：上述为 WSL JDK17、头less Java↔Python 实测；**没有**此次 Windows GUI 人工按钮点击、系统浏览器真实登录/打开成功、平台页面内容读取或实时地区核价，不能写「浏览器自动搜索已打通」。

## 4. 用户如何使用（第一版）

Windows 上在仓库根目录执行 `desktop/start_windows.bat`（JDK17+/Python3.11+）。在第一屏点「京东商城商品发现（只读实验）」，输入关键词并点击打开官方京东搜索。用户自己决定是否登录、查找具体商品、复制1～5条 `https://item.jd.com/数字.html` 链接回来；点「校验粘贴的链接（不联网）」，查看被接受与拒绝的候选，记录仍为**未核商品线索**。

只读商品浏览器操作可能受商城规则限制；无法访问时保持手动访问失败，不调用绕过登录或验证码的代码。不能复制任何账号、Cookie、支付信息到此框。真实购物建议和订单状态仍由原平台证据/用户确认门禁约束。
