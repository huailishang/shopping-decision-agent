# 海纳商品检索 API 首轮实测记录（2026-11-10）

## 结论

海纳开放平台的「商品检索 Pro」已从公开文档/候选供应商阶段推进到**真实 API 可调用**阶段。用户已自行注册并取得 API Key；用户提供的真实响应显示 `error_code=0`、`error_msg=Success`，一次查询返回 20 条商品记录，覆盖京东和淘宝精选。

因此，项目层面的**第一阶段商品发现入口已打通**：现在可以通过一个第三方商品数据 API 获得跨商城的真实商品候选，不应再把“没有任何可调用商品发现 API”列为当前首要瓶颈，也不应继续重复寻找静态商品库或空 SDK。

本记录只确认本次查询成功，不把它扩大解释为全品类、全平台、全量 SKU 覆盖，也不代表商品身份、当前成交价、库存、用户地区到手价、数据使用授权或购买资格均已解决。

## 2. 返回数据字段

本次响应包含：

- 商品身份线索：`title`、`brand_name`、`brand_id`、`cate1_name`、`cate2_name`、`cate3_name`；
- 平台/店铺线索：`mall_id`、`mall_name`、`shop_name`、`shop_type`、`url`；
- 价格线索：`price`、`page_price`、`promotional_info`、`price_tags`；
- 评价线索：`comment_cnt`、`good_comments_share`；
- 规格线索：`union_spec`；
- 图片：`main_picture`、`pictures`、`WhiteImage`；
- 搜索相关性字段：`score`。

这些字段可用于商品候选发现、初步去重、型号核对和后续证据检索。不得把搜索相关性 `score` 当作商品质量或推荐分数；不得把评论数/好评率直接推导为可靠性或耐用性。

## 3. 首轮样本的限制与异常

本次只测试一个兄弟打印机关键词，样本不能代表所有品类和平台覆盖。

1. **来源覆盖有限**：本次 20 条中京东 18 条、淘宝精选 2 条。淘宝只有 2 条，不能据此认为两商城召回能力相当；本次没有测试惠普、其他品牌或其他品类。
2. **链接为导购跳转**：京东链接域名为 `union-click.jd.com`，淘宝链接域名为 `s.click.taobao.com`。本次返回的是推广跳转形式链接；这不能单独证明必须由本项目参加分佣，也不能证明可以不受推广归因/数据使用条款限制。非分佣使用、原始商品详情 URL、商品 ID、链接展示和模型处理权限仍需按平台合同/供应商条款核实。
3. **型号与规格存在冲突样本**：
   - 一条标题为 HL-2595DW 的记录，其 `union_spec` 中认证型号却为 MFC-L5728DW；
   - 一条标题为 DCP-B7658DW 的记录，其 `union_spec` 同时出现型号 HL-2260。
   这是本次样本中观察到的具体异常，不能据此推断所有返回数据都错误，但足以要求型号绑定必须经过独立核验。
4. **价格口径未完成验证**：`price`、`page_price`、促销文案及历史价格标签均为供应商返回字段。本次没有对每个商品进行用户地区、登录状态、优惠资格、运费、库存和结算页核价；不能将其认定为实时到手价或可购买报价。
5. **销售项身份仍需补齐**：本次返回字段没有单独、稳定、明确的通用 `platform_item_id` 字段。推广 URL 内可能含平台参数，但不能把跳转链接直接当成已核实的商城 SKU。店铺类型、销售配置、主机/耗材/套装仍需核验。
6. **评论证据不能替代专业证据**：评论数和好评率是汇总字段，不包含本次可独立核验的评论正文、使用时长和具体故障场景，不能直接用于耐用性结论。
