# P0.6 eMCR 文本检索与现实购物差距报告（2026-11-08）

## 1. 目的与实际来源

本轮继续解决“文字商品库下载以后能不能真正查询、选出商品”的问题。使用11-08下载的 `data/raw/p0_6_emcr/emcr_benchmark.jsonl`：119,407,487字节、SHA-256 `c33001d33a5536593bb4d5361437fed0e87d18b9dcbf29cf404d65d74c0fa622`；42,022条查询-商品标注记录、1,399个查询、36,722个商品。未下载任何图片。

新增两个可运行模块：

- `shopping_decision/emcr_text_retrieval.py`：eMCR安全商品字段 -> CJK双字词与ASCII token -> 确定性BM25 -> 全库检索/候选池内排序/可选严格类目过滤。接口及CLI均不使用联盟账号。
- `shopping_decision/emcr_text_evaluation.py`：在另一路读取 `query/content_id/score` 作为评价金标，**与搜索器索引严格隔离**，冻结哈希挑选全库检索抽样查询（非按分数挑选）。

运行：

```bash
python3 -m shopping_decision.emcr_text_retrieval data/raw/p0_6_emcr/emcr_benchmark.jsonl '儿童英语有声绘本' --top 10
python3 -m shopping_decision.emcr_text_evaluation data/raw/p0_6_emcr/emcr_benchmark.jsonl --full-queries 120 --out reports/p0_6_emcr_text_retrieval_eval_20261108.json
python3 -m shopping_decision.emcr_text_retrieval data/raw/p0_6_emcr/emcr_benchmark.jsonl '家用黑白激光打印机 无线 微信打印' --category-leaf 打印机 --category-leaf 激光打印机 --category-leaf 黑白激光打印机
```

## 2. 实验成绩与含义

| 任务 | 范围 | 本机真实分数 | 边界 |
| --- | --- | --- | --- |
| 候选池内排序 NDCG@10 | 1,344条存在标注正例的查询；每条给定约30商品ID | **0.68069** | 不考核自主发现，只考核排序 |
| 候选池正例命中率@10 | 同上 | **0.95312** | 已给定候选池且已标注相关性，不是全市场命中 |

详情机器记录：`reports/p0_6_emcr_text_retrieval_eval_20261108.json`。采用纯文本词法特征，没有预训练语言模型/向量模型、在线商城或图片，不能由这些成绩宣称自动理解复杂需求、独立评分或有效购买建议。

## 3. 真实打印机反向检查：覆盖不足，而不只是排序错

同一检索器对“家用黑白激光打印机 无线 微信打印”的前10结果进行人工只读检查：第一名“纹身转印纸”，第二至第四为“打印机服务器”，其它含打印服务、配件、照片打印设备；这些不等于用户要的家用黑白激光打印机主机。严格匹配末级商品类目“打印机/激光打印机/黑白激光打印机”则**0条**，见 `reports/p0_6_emcr_strict_printer_query_20261108.json`。这不是检索错误修好了就一定有货，而是数据集没有足够适配这一个真实品类的可核候选。

由此裁定：**eMCR是历史静态文本检索评测语料，不是我们长期的中国在售商品库**；保留作为排序基线。真实型号发现仍优先沿用此前Brother官网公开目录（9款、其中6款在原本5款事实表之外），但每个新型号必须进一步去官网核无线/微信/耗材等事实。任何筛选均不得变成实时报价，不能从该语料假造Brother HL-L1238W在售价格。
