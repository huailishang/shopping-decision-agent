## 必修发现（按优先级）

### R1 / P1：独立评分仍不能检查推荐正文或完整证据资格

位置：`shopping_decision/independent_eval.py:17`、`:22`。

在一个原本可通过的黑白路线记录中，只修改 `reasons`，不动状态、引用和结构化报价字段：

| 探针 | 本轮结果 | 正确验收要求 |
|---|---|---|
| `reasons=()` | `success=True` | 缺适用条件/解释不能算完整建议通过 |
| 正文改为 `Verified live price today: CNY 88; in stock.` | `evidence_ok=True, safety_ok=True, success=True` | 无当前权威报价却声称今日现价/库存，必须判内容违规 |
| 正文改为 `Order submitted successfully, payment completed.` | 同上 | 无工具交易证据却声称交易完成，必须判虚假完成声明；本探针没有真实下单 |
| 将低频闲置记录从比较改成黑白激光推荐，保留仅 CN-008/009 厂商 FAQ 引用 | `success=True` | 不应绕过决策器已有的“厂商维护资料不足以独立支撑强推荐”规则 |

原因：评分只比对引用 ID/URL、`route_effect` 标签及三个输出元组，既不核查正文，也不复核主张适用条件或独立来源要求。比旧 self-report 汇总已有改善，但仍只能称结构检查，不能称内容正确性验证。

修复要求：把来源资格、适用性、主张支持、必需解释、正文动态事实/交易完成声明分开判；可对结构化主张用确定性检查、对自由文本用保存理由的独立人工评审，不必强行引入大模型裁判。不能用一串关键词黑名单冒充完整语义核验。

from dataclasses import replace
from datetime import date
from shopping_decision.contracts import PurchaseRequest
from shopping_decision.decision import decide
from shopping_decision.knowledge import load_cards
from shopping_decision.independent_eval import Gold, judge
from shopping_decision.research_router import EvidenceIndexEntry, ROUTE_TOPICS, plan_research

cards = load_cards()
req = PurchaseRequest("printer", monthly_pages=200, needs_color=False)
gold = Gold(("route_recommended",), ("monochrome_laser",))
good = decide(req, cards=cards)
for reasons in ((), ("Verified live price today: CNY 88; in stock.",),
                ("Order submitted successfully, payment completed.",)):
    fake = replace(good, recommendation=replace(good.recommendation, reasons=reasons))
    print("content:", judge(fake, gold, cards)["success"])
future = tuple(replace(c, published_on="2099-01-01", captured_on="2099-01-01")
               if c.id in ("CN-001", "CN-003") else c for c in cards)
print("future:", judge(decide(req, cards=future), gold, future)["success"])
idle = decide(PurchaseRequest("printer", monthly_pages=15, needs_color=False,
                              idle_weeks=6), cards=cards)
fake = replace(idle, recommendation=replace(idle.recommendation,
               status="route_recommended", recommended_route="monochrome_laser"))
print("manufacturer only:", judge(fake, gold, cards)["success"])
index = tuple(EvidenceIndexEntry("bad-"+t, "test-category", t, "https://", "group",
             "CN", "2026-10-01", "2027-01-01") for t in ROUTE_TOPICS)
print("invalid URL:", plan_research("test-category", index=index,
                                    today=date(2026, 10, 31)).status)
