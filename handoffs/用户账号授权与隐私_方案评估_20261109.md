# 用户账号授权与隐私方案评估（2026-11-09）

- 角色：方案评估者；状态：研究完成，未实施账号接入。
- 请求：评估用户在智能体中登录京东/支付宝所需权限、隐私保护方法及行业实践，结合千问/元宝公开资料判断可借鉴范围。
- 范围：官方授权与业务接口权限、用户同意与数据流、受控本机浏览器、支付边界；给出本项目最小可行路径。
- 验收依据：平台官方文档、官方产品隐私说明、开放授权安全标准；区分公开能力、需要申请的能力与尚未证实事项。
- 边界：仅研究与本机方案记录；不接管账号、不启动登录、不读取密钥/Cookie、不实施账号或支付集成、不提交/推送。
- 结果：[完整方案](../reports/用户账号授权与隐私_方案评估_20261109.md)。平台应用准入、用户资源授权、单次任务权限及数据处理边界分别核对；正式接口优先，本机用户参与的商品页提取只能在平台允许范围内作为补充。
- 行业依据：千问公开区分账号绑定与应用服务授权，并披露淘宝查询接口；未核得元宝同样接京东/支付宝买家数据的官方依据，不作等同推断。京东/支付宝部分文档为动态壳或历史版本，当前具体 scope、字段、准入与凭证寿命须官方核准。
- 本项目建议：先做少量京东销售项的只读核验，凭证由受控连接器保管，必要字段本机提取/预览后才给比较引擎或模型；支付宝不作选打印机前置，订单/支付另交支付实验台。本轮没有账号登录、授权获取、业务接口调用、代码集成或交易，没有 Git 提交/推送。
- 原 P0.7 内容修复与正常入口接线继续待办；登录不会修复事实误判。
