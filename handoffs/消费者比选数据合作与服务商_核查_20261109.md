# 消费者比选数据合作与服务商核查（2026-11-09）

- 角色：研究评估者；状态：公开资料核查完成，未批准供应商或申请接入。
- 请求：用户要求仔细核查“适合消费者比较用途的平台合作，或能证明供数权的服务商”，给出具体主体、能力、接入条件和授权证据。
- 方法：优先原平台、供应方官方产品/技术/服务条款及原平台可交叉核实材料；区分 API 产品存在、供数来源声明、实际使用/转供授权和本应用准入。
- 重点：是否支持京东/淘宝跨店候选发现、是否依赖联盟、能否不参与佣金、价格/库存证据等级、是否允许模型处理和必要保存、资质/费用/试用条件。
- 边界：仅公开资料核查，不注册、签约、付费、联系供应方、提交个人信息、读取用户会话或调用未经核准的业务接口；不复制第三方源码/数据；不提交推送。
- 交付：形成具体候选比较与证据分级，明确能推荐继续核验的路线与尚无授权证明的候选；不把市场宣传当已合法供数或已集成。

- 结果：[完整核查及询证草稿](../reports/消费者比选数据合作与服务商_核查_20261109.md)。海纳是第一候选：已实际读取当前开发者工作台、商品REST/MCP文档和Beta公告；API/Key申请流程存在，未登录公开步骤未见联盟绑定前置，但尚无完整合作许可、非分佣条件和供数链证明，未获测试Key。
- 百度优选备选：现场工具/分佣权限分开，但比价详情只加载壳页，官方搜索索引样例含CPS链接，不据此承诺非联盟或现网可用。
- 筛选：京品库明确基于京东联盟；源头淘有分成及模块沙箱限制；OneBound许可链未核准；Elimapi跨境价格口径不同；极鲸云现列海外平台不匹配。本轮无一家被签发“非联盟中立且有权供本应用使用”的通过结论。
