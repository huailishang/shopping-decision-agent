## 用户目标与约束
用户希望像千问/元宝一样，方便地从真实商品需求走到京东/淘宝商品链接。当前无官方全量商品 API 授权，所以优先恢复用户辅助只读链路：用户在自己浏览器选择平台、主动登录、粘贴**官方完整商品详情网址**；程序仅离线校验商品编号并返回可点击的规范链接。不能读取密码、Cookie、账户内容，也不能绕过防爬或把链接当实时价格/机型已核事实。商品销量、库存、地区到手价仍缺。

## 本轮执行修改
- **商城入口**：Java `ShoppingDecisionDesktop.java` 由京东单入口升级为“京东/淘宝”切换，打开公开搜索页；通过 Python `discovery_bridge.py` 审核粘贴链接，提供“打开已校验商品链接”按钮，完全由用户点击触发。旧京东2参数子进程协议仍兼容；3参数新增所选商城。Python `discovery_ingest.py` 新增只接受 `https://item.taobao.com/item.htm?id=数字`、`https://detail.tmall.com/item.htm?id=数字` 等完整链接的严格规范化，不解析 m.tb.cn 短链、不发送网络请求。候选池 `discovery_pool.py` 按平台+ID去重，JD/TB相同数字ID不合并。
- **评估者 R1（高优先级）**：`official_detail_text.py` 保守提取可见正文，跳过 script/style/template/svg/隐藏节点；肯定短语遇到否定、其他型号限定时弃权，未核功能保持未知。4个独立评估者反证全部转为正确拒绝；另测试隐藏、跨型号变体。仍是受控规则，不宣称具备完整自然语言/网页语义理解。
- **评估者 R3**：逐型号详情含时间/来源/原始响应哈希，拒绝未来取证时间；`product_compare.py` 输出详情来源与页数付费套餐提醒；重新联网访问Brother三详情，保存HTML到 Git 忽略的 `data/raw/p0_8_official_details/` 供原字节复算，摘要见 `reports/p0_8_refetched_official_sources_20261109.json`。不会把建议零售价作为到手价。
