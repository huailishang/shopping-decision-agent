# P0.4 执行者自主任务：商城商品发现进入 Java 桌面使用流程（2026-11-07）

**角色**：执行者接 P0.3 原入口和用户“继续”，无需评估者逐条指导。目标：真实可操作、无平台业务密钥的商品发现最小闭环，而不是仅补报告或复制抓取代码。

## 实施范围（只读、安全）
1. Java Swing 增加“京东商品发现（实验）”：用户输入任意品类搜索词；**用户点击**才在本机默认浏览器打开京东官方搜索页，由用户本人决定是否登录、浏览和复制商品详情页链接。本应用不读取 Cookie、页面、账号、验证码、价格/支付。
2. 用户把自己选择的最多5个京东商品完整链接粘回 GUI，调用 Python 离线链接校验与去重、编号归一化；保留来源及操作时间，只输出待核候选。复用 P0.3 `discovery_ingest.py` 与现有 `DesktopBridgeClient` base64 stdout 协议。
3. 新链路有独立入口，与原打印机需求决策分离；不暗中改购买批准/商品模型比较结果。测试 URL 解析、重复、恶意链接、来源权限、无浏览器连接和无实际地区报价。
4. 若任意公网搜索页对用户受限，本应用仅展示浏览器访问失败和其它允许的路径，不尝试绕过登录/风控，也不自动提交采购操作。

## 验收
- Java GUI 源码编译；增加 CLI bridge unittest 与现有 Python 全量/负向回归；读入3条不同商品链接时可输出三个待核销售项；相同商品重复输入只留一条；伪装 JD 域名被拒。
- 保留 `CURRENT.md`、新增 `reports/P0_4_Java商城发现入口_20261107.md` 及源代码/测试。
- **不能夸大**：本轮不是已成功调用 JD 官方 API，也不是平台真实推荐或自动读浏览器。无平台报价、无用户实际 GUI 登录实验前不得称最终集成验收。
