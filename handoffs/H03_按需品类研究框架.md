# H03｜按需品类研究与跨品类复用（2026-10-31）

- **角色**：本轮执行者（设计和最小代码验证）；下一轮：独立评估者。
- **起因**：用户明确反对为生活中每一种商品预先建设整套知识库，要求整理可以跨品类复用的选购方法。
- **范围**：在 H02 打印机验证场旁新增通用知识获取策略、来源目录、证据时效和适用范围判断、按需研究/复用/复核的最小路由器；用未建设品类做反例测试。
- **不做**：不把打印机已暴露样本称作独立验证；不自动爬取/下载/复制消协或商业测评全文；不接入商品账号、实时报价、外部检索或下单，不引入重型RAG。
- **必须保留**：现有 H02 原始执行报告与保留集，不用本任务修改原评分口径。新代码的“复用”仅指已人工核查的元数据能被引用，不能自动证明建议正确。
- **验收**：能对陌生品类形成研究清单；有足够且适用的既有资料可复用；日期到期、地域不符、缺来源触发复核；具体型号/价格不从稳定知识中伪造；打印机既有测试回归通过。
- **提交**：只本地落盘，默认不 Git 提交或推送。

## 执行结果

- `docs/06_按需品类认知与跨品类复用.md`：记录按需知识获取流程、通用/品类/动态三层资产、资料时效与地域隔离、跨类别案例、新品类验收要求。
- `knowledge/source_directory.json`：记录标准平台、消协查询入口、香港消费者委员会等来源角色与许可边界；不是已授权第三方数据库。
- `shopping_decision/research_router.py`：只读纯函数；未知品类可输出待调查知识主题；同品类/有效日期/适用地域/已核查条目可复用；过期/争议/跨地区要求复核；结算必触发实时价格/库存/条款核实。
- `tests/test_research_router.py` 新增11个本地单测。全量 `python3 -m unittest discover -s tests -v` 共 **36/36通过**（原H02单测25个未改）。
- `CURRENT.md`、`README.md`、`docs/01_核心能力与架构.md`、`docs/05_中国大陆消费证据源与开源实现.md` 同步文档入口及适用边界。
