# 连续12阶段工作分解

每阶段都有可见产物、真实入口和退出标准。时间是累计上限检查点，非最低投入；达到最终目标可提前结束。详细交接写本包evidence/executor/checkpoint-阶段ID.json，记录HEAD、产品SHA、实际任务进展、原件、未知、下一命令、已耗/余额。

| 阶段 | 累计检查点 | 工作与可见退出依据 |
|---|---:|---|
| A | 8h | 先实时记账、核当前脏基线与旧独立REVIEW；用B0走粗用途/专家/彩色三案，给出一条“当前问什么、为何问、用户只回答哪项”的真实原型记录。保留缺源和旧失败，不先造功能。 |
| B | 24h | 构造24任务的独立目标/语义回答表；共同重放器只响应真实prompt_field；A/A应一致，错误问题应变坏，提前泄露答案应被拒，资料不一致应报不可比。冻结参考后再改产品。测量失灵即停止产品扩张。 |
| C | 48h | 最小聚焦链：粗用途→短解释→一次本人选择/暂缓→路线或具体补证变化。至少一条同资料任务减少无关必要答复/重复，或补上关键因素遗漏；否则只准一次有因果理由的调整，再无信号停。 |
| D | 72h | 补齐所需认知依据：先复用HP/Brother/RTINGS，必要时查技术原文和独立方法。逐项分支持、反证、范围、日期、缺件；缺源解释不升级倾向。来源新增同时供A/B。可迁必要审核记录到knowledge消除运行依赖交接文件，原文/许可不扩。 |
| E | 96h | 在现有research_router/guide/dialogue_flow内形成下一问题的统一选择：明确当前目标、已确认与暂缓/撤回、会改变路线的因素、现有证据边界。只问一个，允许专家跳过；不问已答；硬缺件不被省问题指标藏掉。 |
| F | 120h | 确认后依同一状态进入路线、适用候选和具体补证；旧维护/主机价/随箱反例合并回归。只在本人明确给情景时算成本，缺数保留未知。彩色必须时停止黑白集合比较。 |
| G | 144h | 真实stdin/普通聊天/Java主屏展示同一focus；短解释可见、完整来源按需展开。按钮参考仅草稿，发送才确认；坏输入/取消/迟到回执/新会话不覆盖。首轮真实窗口至少粗需求、确认、改答3链。 |
| H | 168h | context_builder/允许模型行动消费当前focus引用、状态版本、源版本和未知；受控transport验证引用/注入/陈旧/超预算回退，真实模型0。保存恢复仅保留输入引用，来源/日期/地区变化重算，不缓存可信问题或赢家。 |
| I | 192h | 决定说明预览/新本地路径另存接入当前focus的理由、已答/暂缓/撤回、路线正反依据、未知及一个下一步；取消/写失败不破坏旧文件。完成12复合链和至少10原生事件链，旧20链意图均有对应原件。 |
| J | 216h | 同资料共同基线24公平配对，全部真实产品调用和逐步事件保存；只答被问字段，目标达成即停。复算安全/正确性/未知/无效答复/重复/额外阅读。保留无收益/退化/故障，不删差案。 |
| K | 232h | 收敛最多8轮集中修复，新增四专项、旧业务和12案、全量、精确历史与scope检查；来源与修复单列。A/A与挑战在最终版本再跑，若改测量器按原规则回放全部，不选择性替换。 |
| L | 240h | 标准runner完整L2，逐AC REPORT、COMPARISON、USAGE、原件SHA、摘要生成器、预算/未知段结清。只交真实完成/未完成，等待Evaluator另8留出与独立裁定。 |

## 实现约束的业务解释

聚焦不是删资料：普通人先看到一个有意义的问题，完整依据仍可展开。聚焦也不是少问越好：需要在家彩色或设备条件尚不明时，必须明确问或保留具体未知。不要通过放弃任务、把全部字段设为暂缓、隐藏硬缺证得到漂亮分数。

问题说明至少能回答：为什么现在问；哪种回答会改变什么；不知道时怎样继续；这段解释根据何处以及不支持什么。用户不该被迫提供“维护费100元”或“实际可打1700页”才能继续。

优先复用原状态、研究路由、事实门禁、行动排序及版本机制，最多新增一个薄focus模块。字段多、文本长、引擎复杂、来源数多都不自动是成果。外部资料补不到，可继续本机接线；不得把未知路线包装成已懂全部品类。

不要把长期闲置简化为“激光必买、喷墨必堵”；现有来源仅支持提出维护问题，具体型号/条件需另证。不要将两款黑白研究样本展示成市场全部选项。

## 中途可接续

每个checkpoint提供一条下一步本机命令、正在失败的断言和精确文件，避免下个会话重读大量历史。暂停/上下文切换/机器等待不算有效投入；未知用时不补估作事实。阶段连续，不为每个检查点请求批准。
