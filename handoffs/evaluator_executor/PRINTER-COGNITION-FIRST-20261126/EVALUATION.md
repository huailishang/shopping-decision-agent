# 独立验收：认知是否真的进入用户决定

先核冻结文件/HEAD/索引/保护件，再执行正式L3，随后语义、来源和复合留出。机器绿是必要条件，不替代专业正确性/真实资料审核。未核不能签PASS，旧657通过不是本包已通过。

## 分层验收

AC-01 来源与主张：至少3条真实可复核认知主张、2个独立来源组，含技术/官方原始资料及专业方法/独立试验。逐项核原文支持什么、适用场景/地区/样本、反例/例外、发布与获取日期、许可/推广/转载风险。旧资料只支持方法就只能用作方法。pending、自称approved、模型摘要、合成测试、两个转载不能当真实已核/独立样本。无资料可交未知与工程，业务来源项不能通过。

AC-02 新手导览：从品类/粗用途开始，不先填所有槽位/维护金额。实际首屏告诉用户该想哪些生活问题、参数为何重要/如何表达、几种路线为何考虑或待核、哪些说法有争议。至少功能/使用场景/成本三类参考；不以堆参数/引用数量算质量。独立选3种粗需求看指南是否真正有差异，不把所有用户导向原两款。

AC-03 本人确认：查看指南不改变答案/版本；参考只填草稿，提交才确认。已经明确的硬要求不被指南或模型改写，偏好不自动升硬门槛，未知/暂缓/撤回不当否。至少一个新增使用因素有类型和依据，修改后改变适用性解释/研究任务而非只进history。专家能跳过，无强制测验，不能以“已读”证明理解。

AC-04 真正入口：真实guide stdin及正常render_chat/Java消费同一结构，粗需求可读；旧三参数、工作单兼容。重复键、超界/非有限/bool类型、大小/深度/错版本/恶意指令/来源自证/未知动作可恢复拒绝，不能丢当前有效会话。

AC-05 模型输入：从实际产品原件核认知主张、本人确认、路线依据、型号事实、未知/假设被分别传递，guide版本相同。受控transport可验证建议引用、注入和陈旧回执拒绝，网络/真实模型0。仅新建JSON却没进入context_builder/允许行动不算消费；规则把答案写好不等于真实模型已评估。语义质量由来源参考与独立样本核，不能模型自己出题自己评。

AC-06 决策：先路线/硬要求，再适用候选，最后成本。必须在家彩色且旧两款不能覆盖时，回到路线/候选缺件；不拿研究样本当全部商品。保留正反依据和未知，不把技术资料/评测/评论/型号参数/实价/授权混合。HP维护0→100、主机价和随箱量三干预的下一行动正确；假设未知不强填0，不以软成本复活硬失败。做点测只能声称点测。

AC-07 依赖与恢复：guide版本/认知源撤回/地区变化使相关解释、路线/context/成本依赖失效，其余需求/独立事实保留。本人另存→新进程恢复→当前源/时点重算；旧赢家/指南文字/模型结论/授权、损坏文件/路径不复活不执行。旧工作单0/未知/暂缓/撤回/单位保真，冲突先本人确认。

AC-08 窗口：既有Windows JDK/Python实际按钮/输入→桥→Python→显示；指南、确认、比较/补证、取消/坏值/迟到回执/新会话、保存恢复、决定说明都可操作。反射取控件可以，反射填最终结果不可以；SKIP/截图/桥helper不算完整窗口。说明导出本人预览并选新路径，来源/认知版本/条件/正反证据/未知/下一步/授权false完整，取消/写失败保全旧文件。

AC-09 效果：20链≥18且G01—14核心全过、至少8原生，G01/G05/G13/G14必须窗口。A/B同初始意图/底层偏好/原始资料/商品事实/日期/预算，不能弱化A或只给B新增来源。至少6对有参考依据的配对任务，记录相同/改善/退化/成本和安全。合成回答脚本是离线偏好oracle，不是小白理解提高；无净增益如实判，引用数/文本长不当主指标。另6独立留出不混分母。

AC-10 工程/历史：全部计划预期退出码成立，旧安全语义/原12案/历史6次尝试0接受及缺测不改；旧657行为可按合理迁移解释，不能删断言/跳过/改冻结器刷绿。当前Java版本兼容只精确SHA，历史原件仍核；保护件/HEAD/索引一致，改动全在白名单。

AC-11 过程：180有效小时/6轮替代旧包而非相加；活动会话先记start再工作、结束即end，命令时长另列，未知段不补造。外部读取（含失败）实时逐条计账：执行32/独立12、查询12、同定位失败2次。报告/摘要/物料版本和生成器SHA可复算，现实来源/受控材料/窗口/真人/模型分账。无账号设备交易/模型API/安装/外发/Git提交推送或索引变化。
