# 使用说明（执行中，非最终交付）

已有 Windows 启动入口 desktop/start_windows.bat，已通过本轮 Windows 部分窗口实际验证（G01/G02/G04/G05/G06/G14）。确认品类、用途后查看“选购前先看”，按需点“目前理解/修改”中的条件，参考仅填草稿，必须本人发送才修改。

新增使用因素（本包固定）：idle_weeks_pattern，枚举 often_long / usually_short，表示是否经常连续数周不打印；不是精确周期或技术阈值，无数值单位。用户发送“经常连续多周不用”或“通常每周都会用”才确认；“暂不确定”保留暂缓，“撤回”删除已确认值。依据是既有专业成本方法把维护耗材和长期成本分开，不能由页数代推使用间隔。长期闲置影响和型号具体恢复条件尚未知，因此只改变待核维护问题，不自动淘汰或优选路线，不生成维护费用。专家可直接补条件、不必完成该选项。资料缺失时保留未知。

guide 五字段读操作仍为 worksheet=null、payload={}，普通聊天同源；保存恢复沿现有工作单，最终决定说明和完整验收尚待完成。

工作单新增可选 guide_reference，只含指南编号、版本、来源编号；旧工作单可读。恢复按当前资料重算，引用缺失或变化会显示说明。成本对照允许保存单项上一次个人假设 prior_assumption（候选、字段、旧输入），不保存胜者；再次比较两点才定位决定性字段，不是全范围稳健性。两项均不构成来源自证或购买授权。

资料管理：本机维护者可修改 knowledge/printer_cognition_guide_v1.json 的已知来源 revision/status（active/withdrawn/pending_review）；仅精确已核初始版本和对应原件可支持主张，新版即使写active也待审，不开放自我认证。点击“刷新认知资料”，现有工作单依当前状态重新计算，不清用户确认。测试中的撤回/新版仅受控扰动，执行结束恢复原注册表。

决定说明：点击“预览/另存决定说明”，先核对本轮显示的UTF-8 JSON，再选本地新文件，不覆盖旧文件。说明含当前用户确认、指南/来源版本、候选证据、假设、未知及下一步。取消不写文件，不上传；保存的说明不是可执行输入或订单。需要最新资料时先点击刷新。Windows运行路径已验证使用现有 D:\SoftWare\Anaconda\install\python.exe 和 JDK 17，无新安装。
