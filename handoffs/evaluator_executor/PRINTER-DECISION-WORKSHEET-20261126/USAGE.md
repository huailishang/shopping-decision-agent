# 本机工作单使用说明（当前阶段）
已有Java桌面：在仓根使用既有Windows JDK编译desktop/*.java到本机临时目录，再以既有启动方式运行ShoppingDecisionDesktop；自动化原生验证命令：python3 -X utf8 handoffs/evaluator_executor/PRINTER-DECISION-WORKSHEET-20261126/VERIFY_JAVA.py --role executor。此命令不访问商城。
先在聊天页确认条件；打开“成本与资料”，点创建/重建工作单；填写期间总打印页数、月数、币种、两款硬件/耗材/维护假设，空白=未知，0=明确零，鼓粉分离填是/否。提交后重算；取消草稿回到上次已提交内容。另存已提交工作单只写用户选择的新文件。新建空白会话后恢复，先查看存档条件并显式确认；会重算，不恢复旧赢家。需求改变后须重建，旧成本不适用。来源页可导入待审摘录、撤回或关联当前已有事实，不会访问来源URL。
## 真实stdin协议
命令 python -m shopping_decision.chat_bridge --worksheet-stdin。UTF-8 JSON根对象恰为schema_version:1、action、state（现有聊天状态JSON）、worksheet（创建时null）、payload（对象）。返回原tab/base64字段及worksheet_json、worksheet_fields、worksheet_conditions、worksheet_sources；失败error字段，旧三参数base64协议不变。
create/preview/rebind/inspect payload={}；edit或clear {candidate:null或候选完整名称,field:字段,value:值}；edit_many {changes:[同edit结构]}，最多32且同字段不得重复。import_source {id,candidate,kind,locator,observed_at,excerpt}，kind为manufacturer_excerpt/professional_review/user_comment/quote_lead，日期ISO YYYY-MM-DD；withdraw_source {id}；bind_reference/withdraw_reference {candidate,fact_id}；restore {confirm_saved_conditions:true} 仅空白会话允许显式恢复不同历史条件。当前已匹配会话可preview，不可无确认覆盖。schema工作单包含schema_version、worksheet_id、revision、binding、confirmed、deferred、withdrawn、basis、models、sources；模型values、kind、dependency_fact_ids、dependency_fingerprints、withdrawn_fact_ids，来源status/version由桥处理。basis含pages/months/currency/fee_scope/scenario_version；values含hardware/starter/toner_yield/toner_price/separate_drum/drum_yield/drum_price/drum_starter/maintenance。不得加winner、authorization或自称已审等字段。错误时保留先前工作单，改正输入后再提交。JSON限256KiB，重复键、错误类型、超界值拒绝。
